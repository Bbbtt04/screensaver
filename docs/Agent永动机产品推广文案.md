# Agent永动机

让你的 AI Agent 在后台继续工作。

当 Claude Code、Codex、Cursor Agent 或脚本任务需要长时间运行时，Agent永动机会为所有显示器盖上一层隐私遮罩，防止旁人看到屏幕内容或误操作电脑。你回来后输入密码即可恢复桌面。

主要能力：

- 多屏全屏遮罩，主屏支持密码解锁
- 自动防休眠，后台任务不中断
- 拦截键鼠误操作
- 默认密码提醒，引导修改安全密码
- Claude 小宠物 loading，让等待没那么冷冰冰

## 核心卖点

### 1. 给长时间 AI 任务一个安全的后台环境

你可以让 AI Agent 继续跑测试、改代码、分析日志或执行脚本。Agent永动机只覆盖屏幕和拦截本地输入，不会阻断后台命令、网络请求或远程 SSH 查看。

### 2. 离开工位时不再裸奔

办公室、实验室、共享工位里，屏幕上可能有代码、密钥、客户信息或实验数据。启动 Agent永动机后，所有显示器都会进入黑色遮罩，主屏显示解锁框。

### 3. 防误触，防打断

全局拦截鼠标和键盘事件，降低同事、路人或自己误触导致任务中断的风险。

### 4. 自动防休眠

启动永动机后自动调用 macOS `caffeinate -d -i -m -s`，尽量保持 CPU、磁盘、显示器和系统唤醒，适合长任务场景。

### 5. 有一点可爱

主屏遮罩上会显示 Claude 小宠物 loading 动画，提示后台任务正在工作。它不泄露代码内容，只让你知道机器还在忙。

## 适用场景

- 让 Claude Code、Codex、Cursor Agent 执行长任务时临时离开
- 跑本地测试、构建、数据处理脚本时需要保护屏幕
- 办公室、实验室、共享空间中保护屏幕隐私
- 远程通过 SSH / VS Code Remote 观察任务进度，但本机屏幕不想被看到

## 不适合什么

Agent永动机不是系统级安全边界，也不是 FileVault 或 macOS 锁屏的替代品。

它不能防止：

- 物理断电或重启
- 管理员强制退出
- 合盖导致的系统睡眠
- 已经有管理员权限的人绕过本地限制

它适合防偷窥、防误操作、防普通工位干扰。

## 下载页说明

当前版本：内部测试版

安装方式：

1. 下载 `Agent永动机.dmg`
2. 打开 DMG，把 `Agent永动机.app` 拖到 Applications
3. 第一次打开如被 macOS 拦截，请右键选择「打开」
4. 在系统设置中为 `Agent永动机.app` 添加权限：
   - 隐私与安全性 -> 辅助功能
   - 隐私与安全性 -> 输入监控

默认解锁密码为 `123456`。首次启动会提醒你修改密码，请尽快设置自己的解锁密码。

## 权限解释文案

为了遮罩和拦截本地输入，Agent永动机需要以下 macOS 权限：

- 辅助功能：用于更可靠地拦截本地键鼠操作
- 输入监控：用于识别并阻止键盘输入干扰

Agent永动机不会上传你的代码、屏幕内容或密码。

## 测试反馈问题

请测试时关注：

- 多屏幕是否全部被遮罩
- 主屏密码输入是否正常
- 外接键盘、鼠标、触控板是否会被拦截
- Claude/Codex/Cursor Agent 任务是否继续运行
- 解锁后桌面是否恢复正常

反馈时请附上：

- macOS 版本
- 芯片型号，Apple Silicon 或 Intel
- 显示器数量
- 是否使用外接键鼠
- 问题复现步骤
